# PARALLAX NERVE

A portable tactical node (pocket cyberdeck) running a custom Linux environment. It acts as a personal assistant for network analysis, authorized defensive auditing, and digital environment monitoring.

## Overview
PARALLAX NERVE leverages a local Small Language Model (SLM) to understand natural language intents and execute local cybersecurity tools (like Nmap, Kismet) in a sandboxed environment.

Please refer to the `ROADMAP.md` for project phases and vision.

## Disclaimer
This project is intended for educational purposes and authorized auditing only. Use responsibly.
